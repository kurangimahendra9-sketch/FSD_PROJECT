About Smart Tourist Explorer

Smart Tourist Explorer is a tourism guidance website designed to help travelers discover destinations across India from one simple interface.

The system provides destination information, categories, trip preferences, budget filtering, food suggestions, restaurant information, temple destinations and Google Maps navigation.

The project is developed using only front-end technologies: HTML, CSS and JavaScript.
